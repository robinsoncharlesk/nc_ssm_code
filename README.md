# Hidden Histories Oracle

An interactive web-based tool where high school students can have conversations with computing's erased pioneers. This educational application honors six groundbreaking computer scientists whose contributions were forgotten or erased from history.

## The Pioneers

1. **Ada Lovelace (1815-1852)** - The First Programmer
2. **The ENIAC Six (1945-1946)** - Betty Holberton, Kay McNulty, Marlyn Wescoff, Ruth Lichterman, Betty Jennings, Frances Bilas
3. **Grace Hopper (1906-1992)** - The Queen of Code
4. **Katherine Johnson (1918-2020)** - The Human Computer
5. **Dr. Gladys West (1930-present)** - The Hidden Mind Behind GPS
6. **Radia Perlman (1951-present)** - The Mother of the Internet

## Features

- **Interactive Conversations**: Students can ask questions and receive responses in the authentic voice of each pioneer
- **Educational Content**: Each pioneer has a detailed biography, key quotes, and context about their contributions
- **Suggested Questions**: Curated questions help guide student learning
- **Custom Questions**: Students can ask their own questions and receive contextual responses
- **Mobile-Responsive**: Works on phones, tablets, and Chromebooks
- **Beautiful Design**: Museum-like aesthetic with deep blues, warm golds, and soft whites

## The Experience

1. **Home Screen** - Browse all six pioneers with their era and title
2. **Meet Screen** - Learn about a pioneer's life, work, and why they matter
3. **Ask Screen** - Choose suggested questions or write your own
4. **Response Screen** - Read authentic responses with citations and context

## Technology Stack

- **React** - UI framework
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Styling and responsive design
- **Single-file architecture** - All logic in one component for simplicity

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The application will run at `http://localhost:5173/`

## Educational Purpose

This tool was built to:

- Honor the pioneers who were erased from computing history
- Teach students about the real people who invented computer science
- Make history feel alive and personal
- Encourage curiosity about the origins of technology
- Highlight the contributions of women and people of color in computing

## Design Philosophy

The tool should feel like meeting someone, not using software. The design is:

- **Simple but profound** - No gamification, no complexity for complexity's sake
- **Respectful** - Honors the seriousness of erasure while being inviting
- **Authentic** - Responses reflect each pioneer's voice and perspective
- **Educational** - Every interaction teaches something real

## Voice Characteristics

Each pioneer has distinct voice characteristics that make their responses authentic:

- **Ada Lovelace**: Poetic, philosophical, draws analogies to art and music
- **The ENIAC Six**: Collective "we," practical, wry humor about being overlooked
- **Grace Hopper**: Direct, witty, no-nonsense, challenges convention
- **Katherine Johnson**: Confident but humble, precise, encouraging to young people
- **Dr. Gladys West**: Humble, focused on the work itself, methodical
- **Radia Perlman**: Technical but accessible, self-deprecating, allergic to hype
